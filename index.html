// --- إدارة سلة الشراء وتجميع العناصر والتعديل على الكميات --- let cart = []; // إضافة عنصر للسلة مع الدمج التلقائي إذا كان الصنف والنوتات مطابقة function addToCart(itemName, price, options = {}) { // إنشاء مفتاح فريد لدمج العناصر المتشابهة ذات نفس التفضيلات const optionsKey = JSON.stringify(options); let existingItem = cart.find(item => item.name === itemName && item.optionsKey === optionsKey); if (existingItem) { existingItem.qty += 1; // زيادة الكمية إذا كان الصنف موجوداً سابقاً } else { cart.push({ name: itemName, price: price, qty: 1, options: options, optionsKey: optionsKey }); } renderCart(); } // تعديل الكمية يدوياً من خانة الإدخال function updateQuantity(index, newQty) { let parsedQty = parseInt(newQty); if (isNaN(parsedQty) || parsedQty <= 0) { parsedQty = 1; // الحد الأدنى للكمية } cart[index].qty = parsedQty; renderCart(); } // حذف عنصر من السلة function removeFromCart(index) { cart.splice(index, 1); renderCart(); } // عرض عناصر الفاتورة مدمجة على الشاشة function renderCart() { const cartContainer = document.getElementById('cartItemsContainer'); // تأكد من مطابقة الـ ID لديك if (!cartContainer) return; cartContainer.innerHTML = ''; let totalAmount = 0; cart.forEach((item, index) => { let itemTotal = item.price * item.qty; totalAmount += itemTotal; cartContainer.innerHTML += `
${item.name} (${item.qty}x)
${itemTotal.toFixed(3)} د.أ
`; }); // تحديث المجموع النهائي const totalElement = document.getElementById('finalTotal'); if (totalElement) totalElement.innerText = `${totalAmount.toFixed(3)} د.أ`; }
